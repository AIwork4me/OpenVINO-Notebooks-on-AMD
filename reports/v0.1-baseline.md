## Baseline validation schema

- schema: v1 (implicit; no `schema_version` field in evidence files)
- evidence set per attempt: `hardware.json`, `upstream.json`, `execution.json`,
  `metrics.json`, `summary.md`, `stdout.log`, `stderr.log`, `executed.ipynb`,
  plus `validation.json` for evaluated runs
- no `software-before/after.json`, no `device-proof.json`, no `aggregate.json`
  (these are introduced by Evidence Schema v2)

## Baseline environment

- Reference platform: AMD Ryzen AI Max+ PRO 395 (16C/32T), Radeon 8060S iGPU
  (gfx1151), 94 GiB shared RAM
- OS: Ubuntu 24.04.4 LTS, kernel 6.17.0-1032-oem
- Python 3.12.3, shared `.venv-cpu` / `.venv-gpu` (per-workload isolation is a
  v0.2 change; the baseline uses shared mutable venvs)

## Historical evidence policy

All v0.1 evidence directories under `results/` are historical records and are
preserved unmodified. They are NOT rewritten into Evidence Schema v2; v2
results are produced by new campaigns. Legacy green results are marked
REVALIDATION_REQUIRED (see `reports/revalidation-migration.md`).
