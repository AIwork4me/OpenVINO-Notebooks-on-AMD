# ROCm Top-20 Expansion — Candidate Set (v0.3)

no duplicate of the existing 8. Model sizes are checked against the gfx1100 48GB
validation GPU. Every twin runs official PyTorch implementations — no kernel
rewrites.

## Correctness contracts (per §31)

- TTS: finite waveform, 24kHz, >1s, RTF, deterministic across runs (int-scale tolerance)
- ASR: expected transcript fragment + CER
- Embedding: shape, finite, cosine-similarity ranking sanity (query closer to relevant doc than irrelevant)
- Reranker: relevance ranking order + finite scores
- OCR/VLM: nonempty markdown/text output containing expected fragment from a pinned input image
- Detection: valid boxes/classes/confidences on a pinned input
- Image gen: valid dimensions, finite pixels, seed-stable

## Repeatability

warmup >= 1, measured runs >= 3 for all (all chosen models fit GPU; no
single-run limitations expected).
