### The four previously-blocked candidates — RCA outcomes

1. **Qwen3-TTS — VERIFIED.** The v0.3 "transformers-version conflict"
   conclusion was WRONG: the model snapshot was incomplete (speech_tokenizer/*
   files missing; transformers 4.57.3's feature-extractor loader failed on the
   absent preprocessor_config.json). Completing the snapshot + the notebook's
   actual speaker ("ryan", not "Cherry") + per-run seeding (greedy decode has
   GPU stop-time variance) → deterministic 3-run generation, RTF 1.27–2.48,
   RMS 0.117. Evidence: `results/qwen3-tts/20261008T184029Z-gpu`.
2. **DeepSeek-OCR-2 — VERIFIED.** Remote code targets the transformers 4.4x
   generation (LlamaFlashAttention2 et al.): rebuilt bridged `.venv-gpu-tf446`
   (4.46.3 over ROCm torch); completed the model snapshot (6.78 GB weights);
   AutoTokenizer needed the repo-declared LlamaTokenizerFast (config auto_map
   omits AutoTokenizer); the official `infer(..., eval_mode=True)` API returns
   real markdown ("Aspire OCR and Barcode Recognition…"). TASK_SEMANTIC
   fragment gate + stability across 3 runs. Evidence:
   `results/deepseek-ocr/20261008T184205Z-gpu`.
3. **Florence-2 — VERIFIED.** 2024-era remote code requires the 4.4x
   generation; the same tf446 env loads it cleanly (5.17 and 4.57 both drift).
   Accurate detailed caption of the fixed fixture including the distinctive
   observation-deck binoculars. Evidence: `results/florence2/20261008T184150Z-gpu`.
4. **YOLO26 — BLOCKED_DEPENDENCY (upstream artifact defect; NOT a ROCm issue).**
   The official yolo26n.pt was obtained via the reachable api.github.com
   release-asset route and is byte-identical to the official Ultralytics
   HF-org mirror (sha256 `9b09cc8b…`) — the v0.3 "mirror artifact mismatch"
   theory is refuted. The artifact itself is inference-degenerate: max
   detection confidence ~0.5 sigmoid(0) garbage (6589 nonsense boxes incl.
   zebra/giraffe on a NYC street) via legacy decode and ~0.01 via predict(),
   across ultralytics 8.3.222 (the checkpoint's save version), 8.4.43 (the
   notebook's pin) and 8.4.173, CPU and gfx1100, plus the native end-to-end
   head decode. Evidence: `results/yolov26-object-detection/20261008T171656Z-gpu`.
