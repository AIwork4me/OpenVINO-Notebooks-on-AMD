## Cross-cutting findings

1. **No twin pins a model revision in code** (`from_pretrained(MODEL)` resolves mutable
   `main`). Workload manifests record revisions observed at validation time; code does
   not enforce them. Evidence revisions were re-verified live (2026-10-08) to still
   match current repo SHAs — but future drift would silently invalidate VERIFIED claims.
   → Phase 2/3 fix: pin `revision=` in every twin + record in metrics.
2. **License corrections required**: smoldocling (cdla-permissive-2.0), minicpm-v-4.6
   (plain apache-2.0), sd-2-1 (openrail++), sdxl (openrail++ — v0.3 report omitted it).
   License verification sources: HF model cards / ModelScope API, verified 2026-10-08.
3. **Runtime input downloads are unverified** (size>0 only). Asset manifest + SHA256
   scheme designed in Phase 2.
4. **courtroom.wav** (897102 B, sha256 `1a0db8c5aefc…328699`, 14.02 s, 16 kHz): canonical
   upstream source is the whisper-asr-genai notebook's own download URL
   (`huggingface.co/datasets/Xenova/transformers.js-docs/resolve/main/courtroom.wav`);
   dataset repo carries no license → **not committed**; managed download + hash instead.
5. **doc_markdown.png** (sha256 `10019a6734a9…ec37a`, MIT-licensed source space
   `khang119966/DeepSeek-OCR-DEMO`) — redistributable; committed as managed fixture.
6. **paddleocr_vl test.png** (sha256 `2cb64a6b…fbcad0`) ships in the Apache-2.0 upstream
   notebook — redistributable; committed as managed fixture.
7. **coco.jpg** (sha256 `30311db1…90a20`) ships in the Apache-2.0 openvino_notebooks
   data tree — redistributable; committed as managed fixture.
8. Execution validity of all 16 historical runs is **unaffected** — these findings
   concern independent reproducibility, not the truth of recorded evidence.
